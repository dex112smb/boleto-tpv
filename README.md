# Boleto TPV

Primera versión Android para taquilla de feria con Bluetooth Classic SPP e impresión ESC/POS.

Incluye interfaz oscura, precios editables sin PIN, selección de impresora emparejada mostrando su nombre real, impresión de prueba y bloqueo de botones mientras imprime.

Esta versión NO contiene comandos para borrar, guardar ni reprogramar gráficos NV de la impresora.
